**Rule 2 — Weather data is stale** (> 31 min old, or never received):
> Fall back to the BH1750 light sensor. If lux is **between** `luxNightThreshold (30 lux)` and `luxCloudyThreshold (10,000 lux)` → CLOUDY. Above 10,000 lux = sunny = FULL_MODE. Below 30 lux = actually dark = doesn't reach this branch (LED_CONTROL is off).

- Forces `isSleepMode = true` on every loop tick — device sleeps between each LoRa/sensor cycle instead of staying awake continuously

4. Errors and fixes:

- **Battery protection never firing in setup**: `digitalStablesData.batteryVoltage` is 0 in setup (readSensorData never called there). Fix: use `quickReadBusVoltage()` directly.

- **Dead zone at 2.80V after raising commaVoltage**: Sleep check `> 2.8` literal didn't fire at exactly 2.80V; COMMA check `< 2.80` also didn't fire. Fix: changed to `>= commaVoltage` for sleep, `> commaVoltage` for LED/WiFi guards.

- **snr field conflict**: Tried to use `digitalStablesData.snr` for weather flag but Annabelle overwrites it with actual radio SNR. Also cannot add new field (244+4=248 = ChinampaData size collision). Fix: used opMode bit 1.

- **goToSleep() heartbeat invisible**: `drawBatteryStatus()` called after `LED_CONTROL` goes LOW. Fix: moved `readSensorData()` and `drawBatteryStatus()` to top of goToSleep() before cutting LED power.

- **WiFi auto-reconnect bypassing shutoff**: `wifiManager.stop()` wasn't preventing ESP32's auto-reconnect. Fix: added `WiFi.setAutoReconnect(false)` and `WiFi.disconnect(true)`.

- **LoRa display at brightness 20 while others at 255**: `sendMessage()` calls `readSensorData()` internally; with battery 3.22V < 3.28V, `readSensorData()` called `FastLED.setBrightness(20)` as side effect. Fix: removed `FastLED.setBrightness(br)` from `readSensorData()`.

- **asyncdata=1 in CLOUDY records**: `asyncdata = 7` was inside `if (getDSDStoredCount() < MAXIMUM_STORED_RECORDS)` guard, not set when memory full. Fix: moved `asyncdata = 7` before the guard.
